# Karneyn Sheets — Windows

Excel dosyalarıyla uyumlu tablo uygulaması [Karneyn Sheets](https://sheets.karneyn.com)'in Windows kurulum dosyaları.

**İndir:** [KarneynSheets-Kurulum.exe](https://github.com/samedcandan/karneyn-sheets-indir/releases/latest/download/KarneynSheets-Kurulum.exe) (Windows 10/11, 64 bit)

- Kurulum tek tıkla biter; masaüstüne ve Başlat menüsüne kısayol eklenir.
- Uygulama her açılışta güncel sürümü kullanır; ilk açılıştan sonra internetsiz de çalışır.
- Tablolarınız yalnız bu bilgisayarda saklanır. Gizlilik: https://www.karneyn.com/sheets/gizlilik
- Windows "bilinmeyen yayımcı" uyarısı verirse: **Ek bilgi › Yine de çalıştır**.
